# Architecture

## Stack

| Layer | Technology | Notes |
|---|---|---|
| UI Framework | React Native 0.86.3 + react-native-web 0.21.2 | Single codebase → iOS / Android / Web PWA |
| UI Toolkit | react-native-safe-area-context, react-native-svg, lucide-react-native | No navigation library |
| State Management | NewsViewModel (class, pub/sub pattern) + React `useState`/`useRef` | No Redux, no Zustand, no Pinia |
| Data Fetching | Supabase JS client (direct) + fetch() to backend REST endpoints | No React Query, no SWR |
| Styling | StyleSheet.create (inline dark theme, no CSS modules) | Single dark palette, no light mode |
| Build | `npx expo export` (Expo bundler) + custom `build-web.mjs` (Vercel deploy) | No webpack, no Vite |
| Backend | Vercel Serverless Functions (ESM) | api/*.js files |
| Database | Supabase (Postgres) with Realtime subscriptions | Table: `market_news`, `user_feeds`, `cron_state` |
| Notifications | expo-notifications (mobile) + Web Audio API beep (web) + FCM V1 (backend push) | No APNs configured |

## Data Flow: News Feed Lifecycle

```
┌──────────────────────────────────────────────────────────────────────┐
│                        SCRAPER PIPELINE                              │
│                                                                      │
│  RSS Feeds ─┐                                                        │
│  Google News ─┤─→ scraper.fetchFeed() ─→ filterFresh() ─→ dedupe()  │
│  User Feeds ─┘    (XML parsing,               (≤24h)       (by URL) │
│                    maxItems=20)                                        │
│                                                                      │
│  All sources → isJunkItem() → buildTitleSelection() → upsertNews()  │
│                   (spam filter)    (title dedup)       (INSERT ON     │
│                                                          CONFLICT     │
│                                                          id DO NOTHING)│
└──────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
                    ┌───────────────────────────┐
                    │   Supabase: market_news    │
                    │   (Realtime enabled)       │
                    └───────────┬───────────────┘
                                │ postgres_changes (INSERT/UPDATE/DELETE)
                                ▼
┌──────────────────────────────────────────────────────────────────────┐
│                      CLIENT (NewsViewModel)                           │
│                                                                      │
│  initialLoad():  cache → emit() → Supabase query → emit()           │
│  subscribeRealtime():  on INSERT → beep + toast + emit()             │
│  polling timer:  every 5 min → refresh() → emit()                   │
│                                                                      │
│  App.js subscribes:  state.items → NewsListView                     │
│                      newItem → NotificationToast (7s auto-dismiss)  │
└──────────────────────────────────────────────────────────────────────┘
```

## Navigation Architecture

**No router library.** Tab navigation is driven by `useState('news')` in `App.js`:

```
MainScreen
├── AppHeader (hidden when GOLD tab active)
├── ConnectivityStrip (visible when offline/just-returned)
├── Tab Content (conditional render by activeTab state)
│   ├── NEWS    → NewsListView (FlatList + category chips + search)
│   ├── GOLD    → TradingViewScreen (iframe XAUUSD chart)
│   ├── CALENDAR→ EconomicCalendarView (scrollable day groups)
│   ├── FOLLOW  → WatchlistView (keyword matches + bookmarks)
│   └── FEEDS   → SourcesView (source list + add/edit/delete user feeds)
├── NotificationToast[] (new-item notifications, max 3, auto-dismiss 7s)
├── ToastHost (toast service queue, max 3, auto-dismiss configurable)
├── TabBar (5 tabs, animated hide for chart fullscreen)
├── Install Card (PWA install prompt, iOS Safari guide)
└── Update Banner (PWA version update notification)
```

**Article modal** is a full-screen `<Modal>` with `<NewsArticleView>` (reader) or `<NewsWebView>` (embedded browser on native). On web, opening original opens a new tab via `<a target="_blank">`.

## Theming

Single dark theme. Colors defined in `src/config/constants.js:18-45`:

| Token | Hex | Usage |
|---|---|---|
| `background` | `#0B1426` | Deep navy, app background |
| `surface` | `#121826` | Card surface |
| `surfaceAlt` | `#182033` | Input backgrounds, elevated areas |
| `surfaceElevated` | `#202B44` | Banner cards |
| `primary` | `#F5A623` | Gold/Amber accent, CTA, active states |
| `important` | `#FB7185` | Hot/breaking news badge |
| `success` | `#34D399` | Online status, positive changes |
| `danger` | `#FB7185` | Error states, negative changes |
| `text` | `#F1F5F9` | Primary text |
| `textSecondary` | `#9CA3AF` | Secondary text |
| `textMuted` | `#64748B` | Muted/placeholder text |

Typography: Inter/Roboto/system-ui via `FONT_FAMILY`. Tabular numbers via `TABULAR_NUMS = ['tabular-nums']` for financial data alignment.

Light mode: **NOT IMPLEMENTED.** `userInterfaceStyle` is hardcoded to `'dark'` in `app.json`.
